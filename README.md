# Borderlands 4 SHiFT Auto Accepter & Friends Management PAK

Azzy SHiFT Friends Management is a Borderlands 4 utility PAK for faster and easier SHiFT friend management.

It can automatically accept, decline, or ignore friend requests and game invites, mass-remove friends, remove offline friends, protect selected players from bulk removal, and customize the SHiFT interface.

## Features

- Auto accept, decline, or ignore friend requests
- Auto accept, decline, or ignore game invites
- Mass remove friends
- Remove offline friends
- Protect specific players from bulk removal
- Add, search, and remove protected players
- Adjustable polling/check interval
- Adjustable removal batch size
- Optional confirmation before bulk removal
- Custom platform/icon styles
- Floating/shrunk SHiFT menu
- Persistent settings through the SDK companion
- Automatic PAK install/update through the SDK mod
- Session-only fallback when no SDK companion is installed

## Installation

Install the SDK mod into your Borderlands 4 `sdk_mods` folder.

When enabled, it checks for:

`pakchunk90-Windows_90_P.pak`

If the PAK is missing, it installs it automatically. If an older/different version is installed, it updates it. If the correct version is already installed, it leaves it alone.

After a new PAK is installed or updated, restart Borderlands 4 so the new PAK can load.
